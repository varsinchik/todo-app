# Todo App

Простое Todo-приложение на React + TypeScript.

## Функционал

- Добавление задач
- Отметка выполненных задач
- Удаление задач (с подтверждением)
- Очистка выполненных задач (с подтверждением)
- Сохранение данных в localStorage
- Навигация между страницами (Список / Добавить)

## Технологии

- React 18
- TypeScript
- React Router
- Vite
- CSS Modules / обычный CSS

## Запуск локально

```bash
npm install
npm run dev
